# ShareBite

ShareBite is a food and usable goods sharing application designed to help reduce food waste and support a circular economy.

## Features

* Email/password authentication
* Google Sign-In using Firebase Authentication
* PostgreSQL backend deployed on Railway
* Food and item listing management
* AI recommendation feature using Gemini AI
* Map-based nearby listing search
* Profile, sharing statistics, and listing history

## Technology Stack

* Flutter
* Express.js
* PostgreSQL
* Firebase Authentication
* Firebase Admin SDK
* Railway
* Gemini AI
